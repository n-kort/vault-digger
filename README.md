# Vault Digger

> Obsidian Plugin for opening (and logging) random notes from a folder

Have you catalogued all your records (books, films) in your vault? Then pick a random one to listen/read/watch!

Creates another note with a log of the files you opened. Lots of time? Open several, enjoy them all 🎵

## Network use

If **Append Wikipedia link** is enabled in settings, the picked note's title and the words from **Wikipedia search terms** (by default its `artist`/`author` property) are sent to the Wikipedia search API (`en.wikipedia.org`) to find a matching article. Nothing else leaves your vault, and the option is off by default.

## Installation
### From within Obsidian
From Obsidian v0.9.8+, you can activate this plugin within Obsidian by doing the following:

- Open Settings > Third-party plugin
- Make sure Safe mode is off
- Click Browse community plugins
- Search for "Advanced Tables"
- Click Install
- Once installed, close the community plugins window and activate the newly installed plugin
